# Сайт автошколы «100%»

Одностраничный лендинг автошколы. Макет сгенерирован визуальным
дизайн-инструментом (рантайм «dc-runtime»), поэтому HTML-файл использует
шаблонный синтаксис `<sc-if>` / `<sc-for>` / `{{ }}` и `<x-dc>`.

## Файловая структура

```
.
├── index.html                 # Главный файл сайта (единственная страница)
├── support.js                 # Рантайм дизайн-инструмента (НЕ редактировать)
├── image-slot.js              # Компонент-заглушка изображений (НЕ редактировать)
├── .image-slots.state.json    # Состояние картинок в слотах (sidecar, генерируется)
└── assets/
    ├── car-logan.png          # Фото Renault Logan (hero-блок)
    ├── car-sandero.png        # Фото Renault Sandero (hero-блок)
    └── car-side.png           # Фото учебного авто (блок «Услуги»)
```

## Как открыть сайт

1. Запустите локальный HTTP-сервер из этой папки:

   ```bash
   python3 -m http.server 8080
   ```

2. Откройте в браузере: `http://localhost:8080/` (главная страница `index.html`).

Обычное открытие файла двойным щелчком (`file://`) **не** рекомендуется:
рантайм и состояние изображений читаются через `fetch()`, который требует
HTTP.

## Важные замечания

- **Не редактируйте** `support.js` и `image-slot.js` — это сгенерированные
  файлы рантайма (в начале файлов указано *«do not edit»*). Правки сломают
  работу макета.
- **`.image-slots.state.json`** — служебный файл: хранит изображения, вставленные
  в слоты `<image-slot>`. Он лежит рядом с HTML и нужен рантайму. Удалять его нельзя.
- Изображения в слотах (`<image-slot id="...">`) можно заменить перетаскиванием
  картинки прямо на элемент в браузере — изменение сохранится в state-файл.
- React/ReactDOM подгружаются рантаймом с CDN `unpkg.com` автоматически.
  Для отображения нужен доступ в интернет.
- Фото машин в hero-блоке и блоке «Услуги» — обычные `<img>` из папки `assets/`.
